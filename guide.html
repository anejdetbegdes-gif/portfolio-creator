Part A · Build your portfolio

Create your portfolio

  1. 1

    Open the editor

    On the home page, select Create My Portfolio.

  2. 2

    Choose a design

    At the top, pick Professional, Editorial or Dark. You can switch at any time; your content stays the same.

  3. 3

    Add your content

    Click ✎ Edit next to any part of the page to change it, and + Add to add links, projects, experience, education, skills, certifications or your own sections.

    • Upload a profile photo, then drag it or use the sliders to position it.
    • If your name is long, the name size is set automatically. You can also choose L, M or S.
    • Under your title you can add extra lines, such as a minor, a second degree or a Ph.D. plan.
  4. 4

    Preview

    Select Preview to see exactly what visitors will see. Switch between Desktop and Mobile.

Saved in this browser only. Your work saves automatically, but only on this computer and browser. To continue on another computer, use Draft → Download backup, then Draft → Restore backup there.

Export your portfolio

  1. 5

    Export Portfolio

    Select Export Portfolio. In Chrome or Edge a Save window opens with the name index.html: choose a folder you can find (for example Desktop) and select Save. If your computer asks to replace an existing file, choose Yes / Replace. In other browsers the file goes to your Downloads folder.

⚠ File name check

Your file must be named exactly:

✓ index.html✗ index (1).html✗ index(2).html✗ Index.html

If your computer added a number, rename the file to index.html before uploading. Windows may hide ".html": if you only see "index (1)", rename it to "index".

  1. 6

    Check the file

    Double-click index.html. Your portfolio opens in your browser. This is the file you will publish.

Part B · Introduction to GitHub

What is GitHub?

GitHub is a free website where people store, share and show their projects. Developers, analysts and researchers use it as a public record of their work, and many employers look at it. You only need a web browser. Five words are enough to get started:

Account
Your profile. Your username becomes part of your website address.
Repository
A "repo": one folder for one project. It keeps the files and the history of every change.
Commit
Saving a change. Each commit has a short message, such as "Add portfolio".
README
The front page of a repository. It explains what the project is.
GitHub Pages
A free feature that turns a repository into a live website.

Create your account

  1. 7

    Sign up

    Go to github.com and select Sign up. If you already have an account, sign in and go to step 10.

    Use a personal email that you will keep after graduation. You can add your school email later in Settings → Emails.

  2. 8

    Choose a professional username

    Your username becomes your web address: jordan-rivera → jordan-rivera.github.io. Use your name, lowercase, with a hyphen if needed. Avoid nicknames and random numbers.

  3. 9

    Verify and secure your account

    Enter the code GitHub sends to your email. GitHub may also ask you to turn on two-factor authentication (2FA): use an authenticator app or GitHub Mobile, and save your recovery codes somewhere safe.

Optional: add a profile photo and a one-line bio under Your profile → Edit profile. It makes your GitHub look professional when you share it.

Create a repository

  1. 10

    New repository

    + → New repository

    The + is at the top right of any GitHub page.

  2. 11

    Fill in the form

    • Repository name: my-portfolio. Use lowercase letters and hyphens, no spaces. The name becomes the end of your link.
    • Visibility: Public. Free accounts can only publish public repositories.
    • Add README: leave it off for your portfolio.

    Create repository

Upload your file

  1. 12

    Upload index.html and commit

    uploading an existing file or Add file ▾ → Upload files

    Drag in your index.html. Check that the name in the list is exactly index.html. Type a short message such as Add portfolio, then select:

    Commit changes

Upload only your exported index.html. Do not upload the Portfolio Creator's own files. In the browser, each file can be up to 25 MB.

Publish with GitHub Pages

  1. 13

    Turn on GitHub Pages

    Settings → Pages

    Under Build and deployment: Source Deploy from a branch, branch main, folder / (root), then Save.

  2. 14

    Wait for your link

    Publishing usually takes 1 to 10 minutes. The Actions tab shows a green ✓ when it is done. Refresh Settings → Pages to see "Your site is live at" and select Visit site.

    https://your-username.github.io/my-portfolio/

Share and update

  1. 15

    Test and submit

    Open your link in a private window to check it. Then submit the GitHub Pages address to your instructor. Do not submit a file:/// address or the repository page.

Your site is public. Anyone with the link can see it. Do not include your home address, phone number, student ID or other private information.

Updating later

Make your changes in Portfolio Creator (or restore your backup with Draft → Restore backup) and export a new index.html. In the same repository, select Add file → Upload files, drag in the new file and commit. A file with the same name replaces the old one. If you still see the old version, wait a few minutes and press Ctrl + Shift + R.

Shorter link: if you name the repository exactly your-username.github.io, your site is at https://your-username.github.io/, without a repository name at the end.

Use GitHub for your other projects

The same steps work for any class or personal project: create a repository, upload your files and commit. This time, turn Add README on. A good repository has:

  • A clear name, such as sales-dashboard or survey-analysis.
  • A README that answers: What is it? Which tools did you use? What did you find? Add one or two screenshots.
  • Tidy folders, such as data/, notebooks/ and images/. When uploading, you can drag a whole folder.
  • No private data: no passwords, API keys, personal information or confidential company data.

Then add the repository link to the project in your portfolio, so visitors can see your work in detail.

Seeing a "404 File not found" page?

Your portfolio is fine. Check these in order:

  1. File name. In your repository it must be exactly index.html. If it says index (1).html: click the file → ✏️ Edit → change the name → Commit changes.
  2. Address. Use the link shown at the top of Settings → Pages. It ends with your repository name.
  3. Pages is on. Settings → Pages → Deploy from a branch → main → / (root) → Save.
  4. Wait a few minutes. When the Actions tab shows a green ✓, refresh your page.
  5. Public repository. Free accounts can only publish public repositories.
  6. File, not folder. index.html must be on the main page of the repository, not inside another folder.
