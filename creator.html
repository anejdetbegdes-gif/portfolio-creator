    PUBLISH WITH GITHUB PAGES

    Put your portfolio online

    Your file is downloading: look for index.html in your Downloads folder. Double-click it to check that it opens correctly in your browser.

    1. Go to github.com and sign in (or create a free account).
    2. Click + (top right) → New repository. Name it, for example, my-portfolio. Choose Public and click Create repository.
    3. Click uploading an existing file (or Add file → Upload files) and drag in the index.html you exported. Click Commit changes.
    4. Open Settings → Pages. Under Build and deployment, choose Deploy from a branch, branch main, folder / (root), then Save.
    5. Wait 1–10 minutes, then refresh the Pages screen. Your address appears at the top, like https://your-username.github.io/my-portfolio/.
    6. Open the link to check it, then share it with your professor.

    To update later: make changes here, export again, and upload the new index.html to the same repository (it replaces the old one). Changes can take a few minutes to appear.

    Remember: a GitHub Pages site is public. Anyone with the link can see it. Do not include your home address, phone number, student ID or other private information. Only upload the exported index.html — not the Portfolio Creator's own files.
